# Gym Pesos

App de iPhone (SwiftUI, iOS 17+) para registrar el entrenamiento. Se instala gratis con SideStore.

- El proyecto se genera con [XcodeGen](https://github.com/yonaskolb/XcodeGen) desde `project.yml`.
- GitHub Actions compila sin firmar y publica `GymPesos.ipa` en cada push (o a mano desde la pestaña *Actions*).

Última versión, directo para descargar desde el iPhone:
https://github.com/alejosanchezhermelo/gym-pesos/releases/latest/download/GymPesos.ipa
